# I2C 錯誤排除指南

## 問題描述
系統報告 I2C 錯誤：
```
I2C_Error: Code=0x1, Slave=1
I2C_Error: Code=0x1, Slave=0
```
然後程式卡住。

## 錯誤代碼說明
- **Code=0x1**: `HAL_I2C_ERROR_BERR` (Bus Error - 總線錯誤)
- **Slave=1**: IR Slave 1 設備
- **Slave=0**: MPU6050 設備

## 可能的原因

### 1. 硬體連接問題
- I2C 總線上的 SCL/SDA 線路沒有正確連接
- 缺少上拉電阻（I2C 需要 4.7kΩ 上拉電阻）
- 總線上的某個設備沒有供電
- 線路過長或電氣干擾

### 2. 電源問題
- 設備供電不穩定
- 上電時序問題（部分設備需要更長的啟動時間）

### 3. 時鐘配置問題
- I2C 時鐘速度設置不正確
- 總線速度對於線路長度來說太快

### 4. 地址衝突
- 多個設備使用相同的 I2C 地址
- 設備地址配置錯誤

## 修復內容

### 1. 改進錯誤處理
**檔案**: `Libraries/Module/MPU6050/MPU6050.c`
- 在 `MPU6050_init()` 中添加了錯誤檢查
- 每個 HAL_I2C_Mem_Write 調用後都檢查返回狀態
- 如果初始化失敗，不會繼續配置，避免程式卡住

### 2. 輕量級錯誤恢復機制
**檔案**: `Libraries/I2C/i2c_common.c`
- **不重新初始化 I2C 外設**（避免干擾總線和其他設備）
- 只清除錯誤代碼和重置 HAL 狀態機
- 快速恢復，無延遲
- 添加調試訊息輸出

### 3. 設備存在檢測
**檔案**: `Core/Src/main.c`
- 在初始化 MPU6050 前先檢查設備是否存在
- 如果設備不存在，跳過初始化

### 4. 調試輸出
**檔案**: `Libraries/Uart/dataPrint.{c,h}`
- 添加 `dataUart_PrintInitError()` 函數
- 提供更詳細的錯誤訊息

## 排除步驟

### 步驟 1: 檢查硬體連接
1. 使用萬用表測量 SCL 和 SDA 是否連接到設備
2. 檢查上拉電阻是否存在（典型值：4.7kΩ）
3. 確認所有 I2C 設備都有供電
4. 測量電源電壓是否穩定（應為 3.3V）

### 步驟 2: 單獨測試設備
1. 先禁用所有 I2C 設備
2. 逐個啟用設備進行測試
3. 找出導致錯誤的設備

```c
// 在 main.c 中臨時禁用設備：
// 禁用 IR 傳感器
IR_SetSlaveEnabled(IR_SLAVE_1, false);
IR_SetSlaveEnabled(IR_SLAVE_2, false);

// 或註釋掉 MPU6050 初始化
// MPU6050_init(&hi2c3);
```

### 步驟 3: 調整 I2C 時鐘速度
如果總線錯誤持續，可以嘗試降低 I2C 時鐘速度：

**在 CubeMX 中**:
1. 打開 `mainboard.ioc`
2. 找到 I2C3 配置
3. 降低時鐘速度（例如從 400kHz 降到 100kHz）
4. 重新生成代碼

### 步驟 4: 使用邏輯分析儀
如果有邏輯分析儀：
1. 連接到 SCL 和 SDA 線路
2. 觀察總線波形
3. 檢查是否有 ACK/NACK
4. 確認地址是否正確

### 步驟 5: 檢查設備地址
```c
// 使用 I2C 掃描功能查找所有設備
uint16_t foundAddr = I2C_Scan(&hi2c3);
if (foundAddr > 0) {
    // 找到設備
} else {
    // 沒有找到任何設備
}
```

## 常見問題

### Q: 錯誤代碼 0x1 (BERR) 的確切含義是什麼？
A: Bus Error 表示 I2C 總線上檢測到不正確的總線條件，通常是：
- 起始條件後沒有停止條件
- 總線仲裁失敗
- 時鐘拉伸問題

### Q: 為什麼程式會卡住？
A: 已修復。之前可能的原因：
1. MPU6050_init() 中的同步寫入操作等待回應 ✓ 已添加錯誤檢查
2. I2C 外設處於錯誤狀態 ✓ 已實現輕量級恢復機制
3. DMA 傳輸卡住 ✓ 超時和錯誤回調已處理

### Q: 如何知道是哪個設備有問題？
A: 查看 UART 輸出的錯誤訊息中的 Slave ID：
- Slave=0: MPU6050
- Slave=1: IR Slave 1  
- Slave=2: IR Slave 2（如果啟用）
